What it is呢個係咩

In its founder's words:

“We as human talk to ai and then the publishable blog are ready for you in all language imaginable.”

CMS services are not merging or embracing AI the way Dawn does. Everyone already talks to an LLM daily, but they cannot turn that talk into published blogs. OpenBlog is here to help — it lets every human post the way Dawn's founder posts: talk first, publish second.

The engine is one common Dawn library — @dawn-studio/blog — an end-to-end blog service concentrating editing / posting / reviewing / publishing, with UI/UX and Cloudflare infrastructure, an editorial “what blog is next” queue, and generation of new blogs from AI chat history (any LLM).

創辦人原話：

「我哋人類同 AI 講嘢，然後出得街嘅 blog 就準備好俾你 — 所有想像得到嘅語言。」

現有 CMS 服務冇好似 Dawn 咁擁抱、融合 AI。人人每日都同 LLM 講嘢，但冇辦法將嗰啲對話變成出版咗嘅 blog。OpenBlog 就係嚟幫手嘅 — 令每個人都可以好似 Dawn 創辦人咁出文：先講，後出版。

引擎係一條 Dawn 共用 library — @dawn-studio/blog — 一站式 blog 服務，集中編輯 / 發佈 / 審閱 / 出版，連 UI/UX 同 Cloudflare 基建、一條編輯部「下一篇 blog 係咩」隊列，同埋由 AI 對話記錄生成新 blog（任何 LLM 都得）。

END GOAL最終目標

Every human can publish like this. The talk you already have with AI — every day, in any app — becomes a finished, reviewed, published blog in all language imaginable. No blank page, no CMS wrestling: talk, and the blog is ready.

每個人都可以咁樣出版。你每日已經同 AI 講緊嘅嘢 — 任何 app 都好 — 變成一篇完成、審閱好、出版咗嘅 blog，所有想像得到嘅語言。冇空白頁，冇同 CMS 搏鬥：講完，blog 就好。

ROADMAP路線圖

  1. @dawn-studio/blog — the common library: end-to-end editing / posting / reviewing / publishing service, UI/UX + Cloudflare infra.
  2. Dogfood first — hectorchan.com and dawnstudio.app blogs migrate onto it first (today's hand-run sync waves, trilingual pipeline, layout and media cards are the manual prototype of this service).
  3. The editorial queue — a standing “what blog is next” queue driving what gets written and published.
  4. From chat history — new blogs generated from AI chat history, whatever LLM the talk happened in.
  5. Open to every human — publishable blogs for everyone, in all language imaginable.
  1. @dawn-studio/blog — 共用 library：一站式編輯 / 發佈 / 審閱 / 出版服務，UI/UX + Cloudflare 基建。
